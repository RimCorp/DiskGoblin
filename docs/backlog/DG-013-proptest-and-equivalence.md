# DG-013: Add property-based equivalence tests (sequential vs. parallel) and memory regression checks

- **Milestone:** M2 — Performance
- **Type:** chore
- **Priority:** P1
- **Complexity Estimate:** M (45–75 minutes)
- **Risk:** Medium

## Objective
Add property-based tests using `proptest` (`crates/diskgoblin-core/tests/proptest_equivalence.rs`) that generate arbitrary directory hierarchies (including random depths, file sizes, hard links, and symlinks) and prove mathematical invariants and exact equivalence between sequential (`threads = 1`) and parallel (`threads = 4`) scans.

## Context
Completes Milestone `M2` (Performance). Per [`docs/testing-strategy.md` §2 Layer 3](../testing-strategy.md) and [`ADR-005`](../decisions/005-traversal-and-concurrency.md), property testing is our primary defense against subtle concurrency race conditions or aggregation bugs.

## Scope
- `crates/diskgoblin-core/Cargo.toml`: Add `[dev-dependencies]` `proptest = "1"`.
- `crates/diskgoblin-core/tests/proptest_equivalence.rs`:
  - Define a `proptest` strategy generating random tree descriptors (`1..25` directories, `0..80` files with sizes `0..1_000_000`, `0..15` hard links, `0..10` symlinks) and materializing them via `FixtureBuilder`.
  - Verify invariants on every generated tree:
    1. **Sequential == Parallel Equivalence:** `report_seq` (`threads = 1`) equals `report_par` (`threads = 4`) across `root`, `top_directories`, `top_files`, and `errors`.
    2. **Conservation of Bytes:** `root.summary.apparent_size` equals the exact sum of unique (deduplicated) file and symlink sizes generated by the strategy.
    3. **Monotonic Ancestor Invariant:** Every parent directory's `apparent_size` and `allocated_size` is `>=` the sum of its child directories' sizes.
    4. **Top-N Bound & Ordering:** `top_files.len() <= top_n` and `top_files` is strictly ordered by `(metric_size DESC, path ASC)`.

## Out of scope
- Modifying CLI or Desktop code.

## Dependencies
- `DG-012` (Parallel scanner).

## Implementation guidance
- Set `ProptestConfig::with_cases(32)` (or `50`) so filesystem creation stays fast (`< 5 seconds` total test time) while thoroughly exercising edge cases.

## Acceptance criteria
- [ ] All 4 property invariants pass across at least 32 randomly generated synthetic directory trees.
- [ ] Zero flakiness across repeated runs on macOS and Ubuntu.

## Verification
```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test -p diskgoblin-core --test proptest_equivalence
```

## Definition of done
- Property tests pass on CI; Milestone `M2` (Performance) is complete.
